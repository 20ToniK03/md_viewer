# Markdown Viewer (md_viewer)

Локальный просмотрщик Markdown-файлов, работающий целиком в браузере. Это один HTML-файл
(`index.html`) со встроенными стилями и скриптами — без сборки, без сервера, без внешних
зависимостей, кроме CDN-скрипта для диаграмм Mermaid.

Проект поддерживает:

- открытие отдельных `.md` / `.markdown` / `.txt` файлов;
- открытие целой **рабочей папки** (директории) с деревом файлов слева;
- оглавление документа и навигацию по заголовкам;
- 12 готовых тем оформления, выбор шрифта и размера текста;
- диаграммы Mermaid (зум, панорама, полноэкранный режим, экспорт в PNG/SVG);
- копирование кода из блоков;
- drag&drop файлов и папок;
- сохранение настроек между сессиями.

## Быстрый старт

1. Скачайте папку проекта.
2. Откройте `index.html` в браузере (Chromium, Edge, Firefox или любой современный браузер).
3. Используйте кнопки на верхней панели:
   - **Добавить файл** — выбрать один Markdown-файл;
   - **Добавить папку** — выбрать рабочую папку (появится дерево файлов слева);
   - **Скрыть/показать панель** — свернуть левую панель;
   - **Шестерёнка** — настройки вида.
4. Или просто перетащите файл/папку прямо на страницу.

> Для диаграмм Mermaid нужен доступ в интернет (скрипт грузится с CDN). Без него весь
> остальной функционал работает, а блоки Mermaid просто показываются как исходный код.

## Структура файлов

```
md_viewer/
├── index.html     — весь интерфейс, стили и логика (единый файл)
├── favicon.svg    — иконка вкладки браузера
└── README.md      — этот файл
```

Внутри `index.html` выделяются три логических блока:

| Блок | Расположение | Назначение |
|------|--------------|------------|
| `<style>` | `<head>` | Все стили приложения |
| `<script>` №1 | перед `</body>` | Встроенная минифицированная библиотека **marked v11.2.0** (парсер Markdown) |
| `<script>` №2 | перед `</body>` | Вся прикладная логика приложения (IIFE) |

## Технологии и зависимости

| Компонент | Источник | Роль |
|-----------|----------|------|
| **marked v11.2.0** | встроен в HTML (минифицирован) | парсинг Markdown → HTML |
| **Mermaid 11.17.2** | CDN `jsdelivr` (`<script defer>`) | рендеринг диаграмм (flowchart, sequence, gantt и т.д.) |
| **Чистый JS (ES5)** | встроен | вся логика UI |

Выбор ES5 (без классов/стрелочных функций в прикладном коде) сделан сознательно — код
стабильно работает даже в старых браузерах.

## Архитектура

### HTML-разметка

Скелет страницы:

```
body
├── header.topbar                 — верхняя панель
│   ├── .dot, .title, .sub        — логотип, название, имя текущего файла
│   └── .top-actions
│       ├── #toc-top-toggle       — свернуть/развернуть левую панель
│       ├── #open-btn             — «Добавить файл»
│       ├── #open-folder-btn      — «Добавить папку»
│       └── .menu-wrap
│           ├── #settings-btn     — «Настройки»
│           └── #settings-pop     — всплывающая панель настроек
├── .layout#layout                — основной каркас (grid из 3 колонок)
│   ├── aside.toc-panel           — левая панель
│   │   ├── .toc-head > .toc-tabs — вкладки «Оглавление» / «Рабочая папка»
│   │   ├── nav.toc#toc           — оглавление документа
│   │   └── nav.folder#folder     — дерево рабочей папки
│   ├── .splitter#splitter        — разделитель (ресайз панели)
│   └── main.content#content      — отрендеренный Markdown
├── input#file-input              — скрытый input для выбора файла
├── input#folder-input            — скрытый input (webkitdirectory) для выбора папки
├── .overlay#overlay              — подсказка при drag&drop
├── .node-tip#node-tip            — тултип с полным текстом узла Mermaid
└── .toast#toast                  — всплывающие уведомления
```

Ключевые `id` используются только в JavaScript для привязки обработчиков; почти вся
вёрстка строится на классах.

### CSS

#### Дизайн-токены и темы

В `:root` заданы CSS-переменные (design tokens), которыми управляет JavaScript:

- размеры и отступы: `--top-h`, `--toc-width`, `--content-max`, `--radius`, `--font-size`;
- палитра: `--bg`, `--panel`, `--panel-2`, `--fg`, `--muted`, `--border`,
  `--accent`, `--accent-2`, `--accent-soft`, `--code-bg`, `--head-bg`, `--top-bg`,
  `--top-fg`, `--grid`, `--tip-bg`, `--tip-fg`;
- тени: `--shadow`, `--shadow-sm`;
- шрифты: `--font-body`, `--font-head`.

Каждая **тема** — это объект в JS со словарём `vars` (значения всех переменных) и
рекомендуемыми шрифтами. При переключении темы `applySettings()` просто пишет значения
переменных в `document.documentElement.style` — вся страница мгновенно перекрашивается
без перерисовки DOM.

#### Верхняя панель (`.topbar`)

`position: sticky; top: 0` — панель всегда видна. Кнопки `.tb-btn` стилизованы под тёмную
панель через `color-mix()` с цветом `--top-fg`, поэтому корректно выглядят на любой теме.

#### Панель настроек (`.settings-pop`)

Абсолютно позиционированный попап под кнопкой-шестерёнкой. Появление анимируется
`@keyframes pop`. Закрывается по клику вне блока, по кнопке «×» и по `Escape`.

#### Каркас (`.layout`)

Трёхколоночный CSS Grid:

```
grid-template-columns: var(--toc-width) 6px minmax(0, 1fr);
```

- колонка 1 — левая панель;
- колонка 2 — разделитель шириной 6px;
- колонка 3 — контент.

Скрытие панели реализовано классом `.layout.toc-collapsed`, который меняет сетку на
`0px 0px minmax(0, 1fr)`. Ширина панели анимируется через
`transition: grid-template-columns`.

#### Левая панель (`.toc-panel`)

`position: sticky` + `max-height` — панель остаётся на месте при прокрутке и прокручивается
внутри себя. Внутри — колоночный flex:

1. `.toc-head` — заголовок с вкладками (`.toc-tabs`, `.toc-tab`);
2. `nav.toc` — оглавление (`flex: 1 1 auto; overflow-y: auto`);
3. `nav.folder` — дерево папки (аналогично).

Вкладка «Рабочая папка» по умолчанию скрыта (`hidden`), JS показывает её только когда
выбрана папка.

Оглавление строится из ссылок с классами `lvl-1`, `lvl-2`, `lvl-3` — отступы задают
визуальную иерархию заголовков.

Дерево папки — вложенные `<ul class="file-tree">`. Каталоги — кнопки `.dir-toggle`
(стрелка `▸` поворачивается на 90° через `.open`), файлы — `.file-btn` (кликабельные
Markdown) или `.file-other` (некликабельные прочие файлы).

#### Разделитель (`.splitter`)

Тонкая колонка с `cursor: col-resize`. Перетаскивание реализовано через Pointer Events
(см. JS), двойной клик сбрасывает ширину к дефолту.

#### Контент (`main.content`)

Стилизуются стандартные элементы Markdown: заголовки (с нижней границей у `h1`/`h2`),
код (`.code-block` с кнопкой копирования), таблицы, цитаты, изображения (`max-width: 100%`).
Блоки кода с переносом строк активируются классом `body.wrap-code`.

#### Mermaid

- `.mermaid-box` — обёртка диаграммы с панелью инструментов и viewport'ом;
- `.mermaid-viewport` — область с точечной сеткой (radial-gradient) и скроллом,
  скрытым кастомным скроллбаром;
- `.mermaid-inner` — масштабируемый контейнер (`zoom`);
- поддержан полноэкранный режим через `:fullscreen`.

#### Анимации

Определены два набора `@keyframes`:

- `panelIn` — появление панели вкладок (fade + сдвиг вниз 8px, 0.22s);
- `contentIn` — появление контента при смене файла (fade + сдвиг 10px, 0.26s).

Перезапуск анимаций делает JS-функция `replayAnimation()` (см. ниже). Для пользователей с
настройкой «уменьшить движение» анимации отключаются через `@media (prefers-reduced-motion: reduce)`.

#### Адаптивность

- `max-width: 980px` — сужается панель и отступы контента;
- `max-width: 820px` — панель переезжает сверху контента, разделитель скрывается,
  сетка становится одноколоночной;
- `max-width: 560px` — компактные отступы верхней панели.

### JavaScript

Вся логика обёрнута в IIFE `(function () { "use strict"; ... })();`.

#### Состояние и константы

| Переменная | Назначение |
|-----------|------------|
| `SETTINGS_KEY`, `TOC_WIDTH_KEY` | ключи localStorage |
| `DEFAULTS` | настройки по умолчанию |
| `SANS`, `SERIF`, `HUMANIST`, `MONO` | готовые стеки шрифтов |
| `FONTS`, `THEMES` | списки шрифтов и тем |
| `dragDepth` | счётчик вложенности drag-событий |
| `draggingSplitter` | идёт ли перетаскивание разделителя |
| `tocWidth`, `lastOpenWidth`, `MIN_OPEN_WIDTH`, `SNAP_TO_ZERO`, `MAX_TOC_WIDTH`, `DEFAULT_TOC_WIDTH` | ширина левой панели и её границы |
| `mermaidRetries`, `mermaidCounter`, `rerenderTimer`, `tipTimer` | служебные для Mermaid и таймеров |
| `folderEntries`, `folderName`, `currentFilePath`, `fileOpened` | состояние рабочей папки и открытого файла |

#### Иконки

`svgIcon(inner, size)` собирает inline-SVG из строки-содержимого. Все иконки в объекте
`ICONS` наследуют `currentColor`, поэтому автоматически перекрашиваются темой. Набор:
`open`, `openActive`, `folder`, `folderFilled`, `folderOpen`, `file`, `fileFilled`,
`settings`, `toc`, `tocActive`, `copy`, `fit`, `fullscreen`, `zoomIn`, `zoomOut`, `image`,
`code`, `terminal`.

#### Настройки и темы

- `loadSettings()` / `saveSettings()` — чтение/запись в `localStorage` с валидацией и
  подстановкой значений по умолчанию.
- `themeById(id)` — поиск темы по `id` (fallback — первая).
- `buildThemeButtons()` — генерирует кнопки-пресеты тем в сетке настроек.
- `applySettings(rerenderDiagrams)` — применяет тему (пишет CSS-переменные, шрифты,
  атрибуты `data-theme`/`data-scheme`), размер текста, флаги; при необходимости
  пересобирает диаграммы.
- `syncSettingsControls()` — приводит контролы настроек в соответствие текущему состоянию.
- `scheduleMermaidRerender()` — отложенный (220мс) перерендер диаграмм после смены темы.

#### Верхние кнопки и панель настроек

- `#open-btn` → открывает `fileInput` (диалог выбора файла).
- `#open-folder-btn` → открывает `folderInput` (диалог выбора папки).
- Кнопки файла/папки меняют иконку на «закрашенную», когда файл/папка выбраны:
  `updateFileButton()` и `updateFolderButton()`.
- `openSettings()` / `closeSettings()` — управление попапом настроек + анимация шестерёнки.
- Закрытие настроек: клик вне `.menu-wrap` и клавиша `Escape`.

#### Оглавление и ширина панели

- `applyTocWidth(width)` — нормализует ширину (ограничения `MIN_OPEN_WIDTH`…`MAX_TOC_WIDTH`,
  «прилипание» к нулю при ширине ниже `SNAP_TO_ZERO`), пишет `--toc-width`, ставит класс
  `toc-collapsed`.
- `updateTocToggle(collapsed)` — обновляет иконку/подпись кнопки на верхней панели.
- `toggleToc()` — свернуть/развернуть панель.
- Разделитель: `pointerdown` (захват указателя), `pointermove` (пересчёт ширины от
  `e.clientX`), `pointerup` (сохранение ширины), `dblclick` (сброс к дефолту).
- Ширина восстанавливается из `localStorage` при старте.

#### Открытие файла

- `handleFiles(files)` — берёт первый файл, сбрасывает папку (`clearFolder()`), ставит
  флаг `fileOpened`, читает и рендерит.
- `readFile(file, cb)` — `FileReader.readAsText(file, "utf-8")`.
- Drag&drop: `dragenter`/`dragover` показывают `.overlay`, `drop` разбирает перетащенное:
  если это **папка** — читает её содержимое, если **файл(ы)** — открывает файл.

#### Рабочая папка

Это самая «насыщенная» часть логики.

- `isFolderOpen()` — есть ли открытая папка (`folderName !== ""`).
- `setFolder(files)` — из `FileList` строит массив `{ file, path }` (путь берётся из
  `webkitRelativePath`).
- `setFolderEntries(entries)` — сохраняет записи, вычисляет имя папки, показывает вкладку
  и рендерит дерево.
- `buildFolderTree()` — строит дерево `{ dirs, files }` из плоского списка путей.
- `renderFolderView()` / `renderFolderNodes()` — генерируют HTML дерева (каталоги
  сворачиваются, файлы `.md`/`.txt` кликабельны).
- Клик по каталогу — раскрытие/сворачивание; клик по файлу — `openFolderFile(entry)`,
  который читает файл и рендерит, **не** закрывая папку.
- `readDroppedEntries(entries, cb)` — рекурсивный обход брошенной папки через
  FileSystem API (`webkitGetAsEntry`), с пакетным чтением `readEntries()`.
- `resolveRelativeImages()` — после рендера файла из папки подставляет относительным
  путям картинок `blob:`-URL, чтобы изображения из той же папки отображались.
- `switchTab(tab)` — переключение вкладок (скрывает/показывает панели + анимация).
- `updateFolderUI()` — синхронизирует вкладку и иконку кнопки папки с состоянием.
- `clearFolder()` — сбрасывает папку (вызывается при открытии обычного файла).
- `replayAnimation(el, cls)` — перезапускает CSS-анимацию (снять класс → `offsetWidth` →
  добавить класс).

#### Рендеринг Markdown

```
render(text)
  content.innerHTML = marked.parse(text)
  buildToc()
  renderMermaidBlocks()
  addCodeCopyButtons()
  resolveRelativeImages()
  replayAnimation(content, "content-enter")
  window.scrollTo(0)
```

- `marked` настроен как `{ gfm: true, breaks: false }`.
- `buildToc()` — находит `h1/h2/h3`, присваивает им `id="sec-N"` и строит ссылки в `#toc`.

#### Mermaid

- `mermaidConfig()` — конфигурация с `securityLevel: "loose"`, `theme: "base"` и
  `themeVariables`, сгенерированными из текущей темы (`mermaidVarsFor`).
- `renderMermaidBlocks()` — находит `pre code.language-mermaid`; если `mermaid` ещё не
  загрузился — ретраи через `setTimeout` (до 25 попыток), иначе помечает ошибку.
- `renderMermaidOne(source, replaceBox, pre)` — асинхронный рендер SVG и подмена блока.
- `buildMermaidBox(svg, source)` — собирает панель инструментов (зум, fit, fullscreen,
  копирование PNG/SVG/исходника).
- `bindPanning(box)` — панорама перетаскиванием и зум колесом с `Ctrl`.
- `decorateNodes(box)` / `bindNodeTips(box)` — подписи узлов с обрезкой и тултипы.
- `svgToPngBlob()` + `copyPng()` — рендер SVG в PNG (canvas) и копирование в буфер.

#### Всплывающие подсказки узлов

`showNodeTip` / `placeNodeTip` / `hideNodeTip` позиционируют `.node-tip` рядом с курсором
и прячут при уходе. Отключаются настройкой «Показывать полный текст узлов».

#### Копирование

- `addCodeCopyButtons()` — оборачивает каждый `pre code` в `.code-block` и добавляет
  кнопку «Копировать код».
- `copyText()` — запись в буфер с fallback на `document.execCommand("copy")`.
- `toast(msg)` — показывает уведомление с анимацией.

#### Инициализация и горячие клавиши

В конце IIFE:

1. выставляются иконки кнопок;
2. `buildThemeButtons()`, `applySettings(false)`, `updateFolderUI()`;
3. обработчик `resize` (пересчёт размеров/масштаба Mermaid);
4. `Ctrl/Cmd+O` — открыть файл;
5. `fullscreenchange` — перенос тултипа/тоста внутрь полноэкранного элемента;
6. отладочный API `window.MDV = { render, settings, rerenderMermaid }`.

## Поток данных

```
[пользователь]
   │
   ├─ кнопка «Добавить файл» / drag&drop файла
   │     └─ handleFiles() → clearFolder() → readFile() → render()
   │
   ├─ кнопка «Добавить папку» / drag&drop папки
   │     └─ setFolder()/readDroppedEntries() → setFolderEntries()
   │            └─ updateFolderUI() → показ вкладки «Рабочая папка»
   │            └─ renderFolderView() → дерево файлов
   │
   ├─ клик по файлу в дереве
   │     └─ openFolderFile() → readFile() → render()
   │
   └─ смена настроек/темы
         └─ applySettings() → CSS-переменные + (опционально) rerender Mermaid

render(text)
   ├─ marked.parse → content.innerHTML
   ├─ buildToc()             → оглавление в левой панели
   ├─ renderMermaidBlocks()  → диаграммы
   ├─ addCodeCopyButtons()   → копирование кода
   ├─ resolveRelativeImages()→ blob-URL для картинок из папки
   └─ replayAnimation()      → анимация появления контента
```

Ключевой момент: **«папка» и «файл» — взаимоисключающие режимы.** Открытие обычного файла
сбрасывает рабочую папку (скрывает вкладку и «разрисовывает» иконку папки), а клик по файлу
*внутри* папки, наоборот, сохраняет контекст папки.

## Кастомизация

- **Добавить тему** — дописать объект в массив `THEMES` (поля `id`, `name`, `scheme`,
  `desc`, `sw`/`swa` для свотча, `fontBody`/`fontHead`, `vars`). Кнопка появится
  автоматически.
- **Добавить шрифт** — дописать запись в `FONTS` и `<option>` в `#font-select`.
- **Изменить границы ширины панели** — константы `MIN_OPEN_WIDTH`, `SNAP_TO_ZERO`,
  `MAX_TOC_WIDTH`, `DEFAULT_TOC_WIDTH`.
- **Изменить анимации** — правила `@keyframes panelIn` / `contentIn` и длительности
  в `nav.toc.panel-enter` / `main.content.content-enter`.

## Совместимость с браузерами

- **Chromium / Edge** — полная поддержка (включая выбор папки через `webkitdirectory` и
  drag&drop папок через `webkitGetAsEntry`).
- **Firefox** — поддержка `webkitdirectory` и `webkitGetAsEntry` в современных версиях;
  остальной функционал работает полностью.
- **Safari** — `webkitdirectory` поддерживается; поведение drag&drop папок может
  отличаться — в этом случае папку можно выбрать только кнопкой «Добавить папку».
- Для Mermaid требуется подключение к интернету (CDN).
